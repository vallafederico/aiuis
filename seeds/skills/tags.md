# Skill tags

The fixed list of tags skills on aiu.is may carry. A collection or slice
schema assigns every skill with a tag by listing it in `skills.tags`; `type`
tags name kinds of documents, `tone` tags a register. `brand-voice` carries
`essay` and `citations`.
