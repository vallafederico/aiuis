Designing the interface for image generation is a different problem from designing the image generator. This chapter focuses on the prompt-to-image loop: how to write prompts, how to read results, how to iterate, and how to know when to stop—and what the UI can do to support each step.

:::notes
The workflow described here converged through iteration on a single project brief over eight weeks.
:::
