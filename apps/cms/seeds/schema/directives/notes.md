# `:::notes` directive guidelines

Use `:::notes` for content that is secondary to the main argument: affiliation disclosures, methodology caveats, contextual asides. The site renders it as a visually distinct block below the main body, outside the table of contents.

One `:::notes` block per document, at the end of the body. If you find yourself wanting a second one, the content belongs inline or in a separate section heading.

No attributes are accepted. The body is standard markdown.
